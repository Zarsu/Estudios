# Estudios de Desarrollo Web

Este repositorio concentra mi proceso de formacion tecnica en desarrollo web, organizado por etapas de estudio y practica.

Durante la primera etapa consolide bases solidas de JavaScript. Actualmente estoy avanzando en Node.js con proyectos orientados a backend y construccion de APIs REST. A futuro, mi enfoque estara en React.js (u otro framework de JavaScript para frontend) para complementar mi perfil full stack.

## Objetivo profesional

Transformar conocimientos academicos en experiencia practica alineada con estandares de trabajo reales, documentando avances progresivos en arquitectura, buenas practicas y herramientas del ecosistema JavaScript/TypeScript.

## Estructura del repositorio

- `Js - The Basics/`: fundamentos de JavaScript mediante ejercicios tematicos.
- `NodeJs/`: proyectos backend en evolucion (APIs, validacion, middleware, modelado de datos y seguridad).

## Avances actuales

### JavaScript Foundations (`Js - The Basics`)

Practica estructurada sobre conceptos clave:

- Variables, scope, coercion, hoisting, closures.
- Arrays, metodos de evaluacion y metodos de arrays.
- Objetos, referencias vs valores.
- Condicionales, bucles, callbacks, arrow functions.
- Event loop y promesas.
- DOM basico con `index.html` + `script.js`.

### Backend con Node.js/Bun (`NodeJs`)

Actualmente en desarrollo de APIs REST y estructura backend profesional:

- `Project-1`: base inicial de autenticacion y validacion. > (actualmente en pausa, para retomar una vez terminado el project-2)
- `Project-2`: API REST en progreso con organizacion por capas (`routes`, `middleware`, `schemas`, `db`) y buenas practicas de entorno.

## Proyeccion

La siguiente etapa del roadmap estara centrada en frontend moderno con React.js (o un framework equivalente del ecosistema JavaScript), priorizando integracion con APIs REST, arquitectura de componentes y experiencia de usuario.
